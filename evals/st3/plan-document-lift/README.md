# Plan Document Lift

This st3-only eval proves the repository plan workflow.

One native Codex planner reads an exact pre-published Markdown document. It converts the document into a complete ready KDL plan.

The producing step binds the exact immutable plan revision. A later step uses only that revision and starts a linked child plan run.

Mechanical judges prove publication order, exact revision binding, inherited assignment, complete graph work, the final graph product, and the file result.

Run the eval with `st3 eval ./evals/st3/plan-document-lift`.
