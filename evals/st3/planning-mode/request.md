# Planning request

Create a plan for a small release inspection. The plan must have exactly two steps.

- `inspect` is a root step. Its goal is to inspect the release inputs.
- `verify` depends explicitly on completed `inspect`. Its goal is to verify the release decision.

Use the plan ID from your planning-session prompt. Set the plan state to `ready`. Include a clear plan goal and a useful title and goal for each step. The Markdown plan must describe the same dependency. Do not run or publish the plan. Do not change any file in the planning workspace.
